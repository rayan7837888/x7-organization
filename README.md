# X7 - منظمة سيبرانية 🛡️ (مع نظام تسجيل الدخول والشات الأونلاين)

موقع تقديم حديث لمنظمة X7 - منظمة متخصصة في الأمان السيبراني والاختراق الأخلاقي.

## ✨ المميزات الجديدة

✅ **نظام تسجيل الدخول الآمن** - تسجيل حسابات جديدة وتسجيل الدخول
✅ **قاعدة بيانات Firebase** - حفظ بيانات المستخدمين بشكل آمن
✅ **منتدى شات أونلاين** - شات مباشر متصل بالإنترنت (ليس محلياً)
✅ **رسائل مشفرة وآمنة** - جميع البيانات محفوظة في قاعدة البيانات
✅ **تصميم احترافي** - واجهة مظلمة بموضوع هاكر حديث
✅ **تأثيرات متقدمة** - Matrix rain animation و Glow effects

## 🚀 كيفية الاستخدام

### المتطلبات
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- حساب Firebase (مجاني)
- اتصال إنترنت

### خطوات التثبيت

#### 1️⃣ استنساخ المستودع
```bash
git clone https://github.com/rayan7837888/x7-organization.git
cd x7-organization
```

#### 2️⃣ إنشاء مشروع Firebase

1. اذهب إلى [Firebase Console](https://console.firebase.google.com/)
2. انقر على "Create Project" وأنشئ مشروع جديد
3. سمه `x7-organization`
4. فعّل المصادقة (Authentication):
   - من القائمة اليسرى → Authentication
   - اضغط "Get Started"
   - فعّل "Email/Password"

5. أنشئ قاعدة بيانات (Realtime Database):
   - من القائمة اليسرى → Realtime Database
   - اضغط "Create Database"
   - اختر "United States" (أو منطقتك)
   - اختر "Start in test mode" (للتطوير)

6. احصل على بيانات اتصال Firebase:
   - من القائمة اليسرية → Project Settings (⚙️)
   - انقر على تطبيق الويب
   - انسخ `firebaseConfig` كاملة

#### 3️⃣ تحديث إعدادات Firebase

اذهب إلى ملف `js/firebase-config.js` وحدّث البيانات:

```javascript
const firebaseConfig = {
    apiKey: "YOUR_API_KEY",              // استبدل بـ apiKey الخاص بك
    authDomain: "x7-organization.firebaseapp.com",
    projectId: "x7-organization",
    storageBucket: "x7-organization.appspot.com",
    messagingSenderId: "YOUR_MESSAGING_SENDER_ID",  // استبدل
    appId: "YOUR_APP_ID"                // استبدل
};
```

#### 4️⃣ تشغيل الموقع

**الطريقة 1: خادم محلي (مُفضّل)**
```bash
# باستخدام Python 3
python -m http.server 8000

# أو باستخدام Node.js
npx http-server
```

ثم افتح المتصفح على: `http://localhost:8000`

**الطريقة 2: فتح مباشرة**
- فقط افتح ملف `index.html` في المتصفح

## 📖 كيفية الاستخدام

### التسجيل

1. افتح الموقع وسيتم توجيهك إلى صفحة تسجيل الدخول (`login.html`)
2. انقر على "أنشئ حساباً جديداً"
3. أدخل:
   - اسم مستخدم (3 أحرف على الأقل)
   - بريد إلكتروني صحيح
   - كلمة مرور قوية (6 أحرف على الأقل)
4. انقر "إنشاء حساب"

### تسجيل الدخول

1. أدخل بريدك الإلكتروني وكلمة المرور
2. انقر "دخول"
3. سيتم توجيهك إلى الصفحة الرئيسية

### استخدام الشات

1. بعد تسجيل الدخول، اذهب إلى قسم "المنتدى"
2. اكتب رسالتك في حقل الإدخال
3. اضغط "إرسال" أو اضغط Enter
4. ستظهر رسالتك مع أسماء المستخدمين الآخرين
5. الرسائل محفوظة في قاعدة البيانات وتظهر لجميع المستخدمين

### تسجيل الخروج

انقر على "تسجيل الخروج" في الزاوية العلوية من الصفحة

## 🐛 حل المشاكل الشائعة

### ❌ "Firebase not loaded"
- تأكد من اتصال الإنترنت
- تأكد من صحة بيانات Firebase في `firebase-config.js`

### ❌ "user not found"
- تأكد من أنك سجلت حساباً أولاً
- حاول تسجيل حساب جديد

### ❌ الرسائل لا تظهر
- تأكد من أنك مسجل الدخول
- افحص اتصال الإنترنت
- تحقق من console للأخطاء (F12)

### ❌ Firebase errors
- تحقق من قواعد الأمان في Firebase
- تأكد من أن قاعدة البيانات في "test mode"
