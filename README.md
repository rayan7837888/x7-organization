# X7 - منظمة سيبرانية 🛡️

موقع تقديم حديث لمنظمة X7 - منظمة متخصصة في الأمان السيبراني والاختراق الأخلاقي.

## ✨ المميزات

- 🎨 **تصميم احترافي** - واجهة مظلمة بموضوع هاكر حديث
- 💬 **منتدى شات** - نظام منتدى مثل المنتدى للحوار بين الأعضاء
- 📱 **مُحسّن للكمبيوتر** - يعمل بشكل مثالي على أجهزة الكمبيوتر (Desktop only)
- 🔐 **تخزين محلي** - الرسائل تُحفظ محلياً في متصفحك (localStorage)
- 🌙 **وضع الليل** - واجهة مظلمة لراحة العيون
- 🎭 **تأثيرات متقدمة** - Matrix rain animation و Glow effects

## 🚀 كيفية الاستخدام

### متطلبات النظام
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- كمبيوتر (Desktop فقط)
- اتصال إنترنت (اختياري - الموقع يعمل محلياً)

### البدء السريع

1. **استنساخ المستودع**
```bash
git clone https://github.com/rayan7837888/x7-organization.git
cd x7-organization
```

2. **فتح الموقع**
   - افتح ملف `index.html` مباشرة في المتصفح
   - أو استخدم خادم محلي:
```bash
# باستخدام Python 3
python -m http.server 8000

# أو باستخدام Node.js
npx http-server
```

3. **زيارة الموقع**
   - افتح المتصفح وقم بالدخول إلى: `http://localhost:8000`

## 💾 إدارة البيانات

الموقع يستخدم `localStorage` لحفظ الرسائل محلياً:

```javascript
// الرسائل تُحفظ في صيغة JSON
{
  id: timestamp,
  username: "User1234",
  text: "محتوى الرسالة",
  timestamp: "02:30:45 ص"
}
```

**ملاحظة مهمة:** البيانات تُحفظ فقط على جهازك الحالي. عند حذف بيانات المتصفح أو استخدام وضع التصفح الخاص، ستُفقد الرسائل.

## 🎨 التخصيص

### تغيير الألوان
عدّل متغيرات CSS في `css/style.css`:

```css
:root {
    --primary-color: #00ff00;      /* اللون الأساسي (أخضر) */
    --secondary-color: #00aa00;
    --dark-bg: #0a0e27;            /* خلفية الموقع */
    --accent-color: #ff1744;       /* لون التنبيه */
}
```

### تغيير أسماء المستخدمين العشوائية
عدّل الدالة `generateUsername()` في `js/chat.js`:

```javascript
const prefixes = ['User', 'Hacker', 'Admin', 'Cyber', 'Security'];
```

## ⚡ الأداء

- ✅ تحميل سريع جداً (بدون مكتبات خارجية)
- ✅ حجم صغير (أقل من 100KB)
- ✅ يعمل حتى بدون إنترنت (بعد التحميل الأول)

## 🔒 الأمان

- لا توجد عمليات خادم (Server-side)
- لا يتم إرسال البيانات إلى أي خادم
- البيانات محفوظة محلياً فقط
- لا توجد معرّفات شخصية حقيقية
